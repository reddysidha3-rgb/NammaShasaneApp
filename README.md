# Namma Shasane

## Project Overview

Namma Shasane is an Android application developed to help citizens report and monitor civic infrastructure issues. The application enables users to upload details, report damages, view locations on a map, and manage reports efficiently.

## Features

* Add and manage Shasana records
* Upload information and supporting details
* Report damaged infrastructure
* View locations using map integration
* Generate and view reports
* User-friendly Android interface

## How to Run

1. Open the project in Android Studio.
2. Sync Gradle dependencies.
3. Connect an Android device or launch an emulator.
4. Build and run the application.
